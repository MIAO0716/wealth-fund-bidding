理财、基金现场竞标系统 · Windows 一键部署包
================================================

【首次使用（新电脑）】
1. 把压缩包解压到任意位置（例如桌面）。
2. 双击「1-启动系统」。
   - 首次会自动安装（约 1 分钟）、初始化数据库，并让你设置管理员密码（账号 admin，至少 10 位）。
   - Windows 可能弹出两次提示：
     · “Windows 已保护你的电脑”：点「更多信息」→「仍要运行」；
     · “是否允许此应用对你的设备进行更改”（放行防火墙端口，手机访问需要）：点「是」。
3. 启动成功后会自动打开管理端；窗口里会显示「手机与大屏使用的地址」。
4. 关闭这个黑色窗口即停止服务。数据自动保存，下次双击「1-启动系统」继续。

不需要安装 Node.js、数据库或其他任何软件，也不需要联网。

【文件说明】
1-启动系统          启动（首次自动安装）。已在运行时直接打开管理端。
2-停止系统          停止服务和数据库。
3-备份数据          生成备份文件并打开备份文件夹，建议另存到 U 盘。
4-恢复数据          从备份恢复（可把备份文件直接拖到它上面）。恢复后需重新发放二维码。
5-重置管理员密码    忘记密码时使用。

【现场使用要点】
- 手机必须与这台电脑连接「同一个 Wi-Fi」才能扫码。建议给电脑设置固定 IP，
  或会前确认地址不变；地址变化时启动窗口会提示，需在管理端重新发放二维码。
- 有的公司/酒店 Wi-Fi 开启了「设备隔离」，手机连不上电脑：可改用一台手机开热点，
  电脑和所有手机都连这个热点（或请网管关闭隔离）。
- 大屏：管理端「二维码与大屏」→「生成大屏链接」，在投屏电脑的浏览器打开并点「全屏」。
  投屏电脑可以就是这台电脑（把链接粘贴到新的浏览器窗口）。
- 首轮发布、项目锁定后系统会自动备份；会后用「3-备份数据」再备份一次。
- 先用「新建演示活动」彩排一遍，演示数据与正式活动完全隔离。

【数据位置】
C:\ProgramData\BiddingSystem\data
  pgdata    数据库
  backups   备份（自动检查点和手动备份）
  logs      运行日志（出问题时把整个 logs 文件夹发给技术人员）
  config.json  端口等设置（一般不用改）。如使用域名或固定地址，可把 publicBaseUrl 改为
               例如 "http://192.168.1.10:8080"，默认 "auto" 为自动识别本机局域网地址。

【换电脑】
在旧电脑运行「3-备份数据」，把备份文件拷到新电脑；新电脑解压本程序后先运行一次
「1-启动系统」完成初始化，关闭窗口，再把备份文件拖到「4-恢复数据」上，最后重新启动。

详细说明见仓库 docs 目录：现场操作手册、部署说明。

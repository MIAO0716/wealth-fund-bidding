理财、基金现场竞标系统 · 云服务器部署包
================================================

适用：Ubuntu 22.04 / 24.04、Debian 12，x86_64，建议 2 核 2G 及以上。
与「Windows 一键部署包」相互独立：数据分别保存，可同时存在。

【上线前准备】
1. 云服务器一台（阿里云、腾讯云、华为云等），系统选 Ubuntu 22.04 或 24.04。
2. 域名一个，在域名解析里添加 A 记录，指向服务器公网 IP（例如 bid.你的域名.com）。
3. 中国大陆服务器：域名必须完成 ICP 备案，否则 80/443 端口会被拦截、微信内可能无法打开。
   来不及备案时可选香港或海外服务器（无需备案，访问稍慢）。
4. 云服务器控制台「安全组 / 防火墙」放行 TCP 22、80、443 端口。

【安装（约 3 分钟）】
1. 把本压缩包上传到服务器（如 scp，或云控制台的文件上传），然后：
     tar xzf BiddingSystem-linux-x64.tar.gz
     cd BiddingSystem-linux-x64
     sudo ./install.sh --domain bid.你的域名.com --email 你的邮箱
2. 按提示设置管理员密码（账号 admin，至少 10 位）。
3. 完成后浏览器打开 https://bid.你的域名.com/admin 登录。

脚本会自动：安装数据库与 Nginx、申请免费 HTTPS 证书（自动续期）、设置开机自启与异常自动重启、
每天 03:30 自动备份（保留 30 份）。数据库只允许本机访问。

【日常管理】
  sudo bidding status            运行状态、访问地址、最近备份
  sudo bidding logs              查看日志（-f 持续跟踪）
  sudo bidding restart           重启
  sudo bidding backup            立即备份（会前、会后各做一次，并下载一份到本地电脑）
  sudo bidding backups           列出备份
  sudo bidding restore 备份文件   从备份恢复（会先自动备份当前数据）
  sudo bidding reset-admin       重置管理员密码

数据与备份：/var/lib/bidding（备份在 backups 子目录）；配置：/etc/bidding/bidding.env

【升级】
上传并解压新版本，在新目录里再次运行 sudo ./install.sh（无需参数，沿用原有域名、配置与数据）。

【现场使用】
领导直接用手机流量或任意网络扫码即可，无需连接会场 Wi-Fi；
因此在管理端「准备与配置」中 Wi-Fi 两项留空即可，领导使用卡上不会出现 Wi-Fi 步骤。

【常见问题】
- 证书申请失败：检查域名解析是否已指向本服务器、安全组是否放行 80/443、大陆服务器是否已备案；处理后重新运行 install.sh。
- 微信里打不开或提示「非微信官方网页」：域名未备案或被拦截，建议完成备案；也可让领导点右上角「在浏览器打开」。
- 忘记管理员密码：sudo bidding reset-admin

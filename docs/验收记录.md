## 已知限制

- 单进程部署（需求明确不需要微服务）；多实例部署时实时推送依赖 PostgreSQL LISTEN/NOTIFY，已支持，但未做多实例压测。
- 大屏「领先变化」提示与加码高亮依赖浏览器收到推送；降级为轮询时仍会更新数据，但高亮可能不出现。
- 二维码为一次性凭证：领导换浏览器（如从微信切到 Safari）需工作人员重发。
- Playwright 在本环境中对中文附件名的 `suggestedFilename()` 返回 `download`，测试改为直接校验响应头与文件内容；浏览器实际下载使用 `filename*` 中文文件名（另附 ASCII 兜底名）。

# 在自己电脑上体验（Windows）

大约 20 分钟。体验时请使用「演示活动」，演示数据与正式活动完全隔离。

## 1. 安装两个软件（一次性）

1. **Node.js 22 LTS**：<https://nodejs.org/> 下载 Windows 安装包，一路「下一步」。
2. **PostgreSQL 16**：<https://www.postgresql.org/download/windows/> 下载安装包，一路「下一步」。
   - 安装时设置的数据库超级用户 `postgres` 的**密码要记住**；
   - 端口保持默认 `5432`；最后的 Stack Builder 可以直接关闭。

## 2. 下载代码

GitHub 仓库页 → 绿色 **Code** 按钮 → **Download ZIP** → 解压到一个**不含空格的路径**，例如 `D:\wealth-fund-bidding`。

## 3. 建数据库

开始菜单打开 **SQL Shell (psql)**，前几项直接回车，输入安装时设置的密码，然后执行：

```sql
CREATE DATABASE bidding;
```

看到 `CREATE DATABASE` 后输入 `\q` 退出。

## 4. 配置

在项目文件夹里把 `.env.example` 复制一份，改名为 `.env`，用记事本打开，修改这几行（其他保持不变）：

```ini
DATABASE_URL=postgres://postgres:你的数据库密码@localhost:5432/bidding
PUBLIC_BASE_URL=http://localhost:8080
WEB_DIST=../web/dist
BACKUP_DIR=
```

## 5. 安装、构建、启动

在项目文件夹的地址栏输入 `powershell` 回车，打开命令窗口，依次执行：

```powershell
npm ci
npm run build
npm run db:migrate
npm run admin:create -- --username admin --name 工作人员
npm start
```

- `admin:create` 会让你输入两次管理员密码（至少 10 位，输入时不显示）。
- `npm start` 之后窗口保持打开，看到包含 `Server listening at http://127.0.0.1:8080` 的输出即启动成功。关闭窗口即停止。
- 以后再体验只需在该文件夹执行 `npm start`。

## 6. 走一遍流程

同一个浏览器可以同时扮演管理员、大屏和一位领导（三者的登录互不影响）；要扮演第二位领导，请另开一个**无痕窗口**。

1. **管理端**：打开 <http://localhost:8080/admin>，用 `admin` 和刚设置的密码登录 → 点「新建演示活动」。
2. **大屏**：「二维码与大屏」→「生成大屏链接」→ 复制链接，在新窗口打开 → 点「全屏」。
3. **领导手机**：「二维码与大屏」→ 浦东一行点「发放」→ 复制二维码下方的链接，在另一个窗口打开。
   想看手机效果：在该窗口按 `F12` → 点左上角手机图标（设备工具栏）→ 选 iPhone。
4. **发布首轮**：管理端「首轮数据」→「发布首轮并冻结」→ 勾选 → 确认。大屏自动显示首轮榜。
5. **领导认领**：领导窗口点「确认认领基础底标」→「确认认领」。
6. **开始竞标**：管理端「现场控制」→「开始竞标」→ 第一组「开放本组」。大屏切到实时榜。
7. **加码**：领导窗口点「追加5个百分点」→ 核对 →「确认提交」，观察大屏同步变化、金色高亮。
8. **收尾**：管理端依次结束三组 → 自动暂停 →「锁定项目…」→「大屏展示」点「最终结果」→「导出与备份」导出 Excel。

## 7. 用真手机扫码（可选）

1. 在命令窗口执行 `ipconfig`，找到电脑的 IPv4 地址，例如 `192.168.1.10`。
2. 把 `.env` 里的 `PUBLIC_BASE_URL` 改为 `http://192.168.1.10:8080`，重新 `npm start`。
3. Windows 首次启动若弹出防火墙提示，选择「允许」（或在防火墙中放行 8080 端口）。
4. 手机连接**同一个 Wi-Fi**，在管理端重新「发放」二维码，用微信扫码。
   - 修改地址前发放的二维码会失效，需要重新发放。
   - 部分公司或酒店 Wi-Fi 开启了「设备隔离」，手机访问不到电脑，可以改用手机热点让电脑和手机都连上。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| `npm ci` 很慢或失败 | 网络问题，可执行 `npm config set registry https://registry.npmmirror.com` 后重试 |
| `password authentication failed` | `.env` 中 `DATABASE_URL` 的数据库密码不对 |
| `database "bidding" does not exist` | 第 3 步建库没成功 |
| 打开 localhost:8080 显示「接口不存在」 | 没执行 `npm run build`，或 `.env` 中 `WEB_DIST` 不是 `../web/dist` |
| 端口被占用 | `.env` 中把 `PORT` 改成 8090，同时改 `PUBLIC_BASE_URL` |

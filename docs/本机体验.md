# 一键部署（Windows）

适用于在**任意一台 Windows 10/11 电脑**（包括全新电脑）上运行，现场局域网使用。不需要安装 Node.js、数据库或其他软件，也不需要联网。

## 下载

直接下载最新版：**[BiddingSystem-windows-x64.zip](https://github.com/MIAO0716/wealth-fund-bidding/releases/latest/download/BiddingSystem-windows-x64.zip)**（链接固定，始终是最新版）。

也可以在 GitHub 仓库页 → 右侧 **Releases** → 标有「Latest」的「Windows 一键部署包」中下载。不要用「Code → Download ZIP」，那是源代码。

每个版本都由 GitHub 的 Windows 构建机自动打包，并已在 Windows 上自动验证：启动、扫码、加码、锁定、导出、停止、重启、备份、恢复、重置密码。

## 使用

1. 解压到任意位置（例如桌面）。
2. 双击 **`1-启动系统`**：
   - 首次会自动安装（约 1 分钟）、初始化数据库，并让你设置管理员密码（账号 `admin`，至少 10 位）。
   - Windows 可能弹出提示：「Windows 已保护你的电脑」→ 点「更多信息」→「仍要运行」；「是否允许此应用对你的设备进行更改」（放行防火墙端口，手机访问需要）→ 点「是」。
3. 自动打开管理端，窗口显示「手机与大屏使用的地址」。**关闭这个黑色窗口即停止服务**，数据自动保存。

| 文件 | 作用 |
| --- | --- |
| `1-启动系统` | 启动（首次自动安装）；已在运行时直接打开管理端 |
| `2-停止系统` | 停止服务和数据库 |
| `3-备份数据` | 生成备份并打开备份文件夹（建议另存 U 盘） |
| `4-恢复数据` | 从备份恢复（可把备份文件拖到它上面） |
| `5-重置管理员密码` | 忘记密码时使用 |

数据保存在 `C:\ProgramData\BiddingSystem\data`（数据库、备份、日志、`config.json`），升级程序不会影响数据：下载新版本解压后直接运行 `1-启动系统` 即可。

## 走一遍流程

同一个浏览器可以同时扮演管理员、大屏和一位领导；第二位领导请开**无痕窗口**。

1. 管理端「新建演示活动」。
2. 「二维码与大屏」→「生成大屏链接」→ 在新窗口打开 →「全屏」。
3. 浦东「发放」→ 用手机扫码（或复制二维码下方链接在另一窗口打开，按 F12 切换手机视图）。
4. 「首轮数据」→「发布首轮并冻结」；领导「确认认领基础底标」。
5. 「现场控制」→「开始竞标」→ 第一组「开放本组」；领导「追加5个百分点」→「确认提交」，大屏同步变化。
6. 结束三组 →「锁定项目…」→「最终结果」→「导出与备份」导出 Excel。

## 手机扫码注意

- 手机与电脑连接**同一个 Wi-Fi**。启动窗口显示的「手机与大屏使用的地址」就是二维码里的地址。
- 电脑的局域网地址变化后（换网络、重启路由器），启动窗口会提示，需要在管理端重新发放二维码。会场建议给电脑设置固定 IP。
- 公司或酒店 Wi-Fi 若开启了「设备隔离」，手机访问不到电脑：可用一部手机开热点，电脑和所有手机都连这个热点，或请网管关闭隔离。
- 需要固定地址或使用域名时，编辑 `C:\ProgramData\BiddingSystem\data\config.json`，把 `publicBaseUrl` 从 `"auto"` 改为例如 `"http://192.168.1.10:8080"`。

## 换电脑

旧电脑运行 `3-备份数据`，把备份文件拷到新电脑；新电脑解压本程序，先运行一次 `1-启动系统` 完成初始化并关闭窗口，再把备份文件拖到 `4-恢复数据` 上，最后重新启动。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 双击后窗口一闪而过或报错 | 查看 `C:\ProgramData\BiddingSystem\data\logs`，把整个 logs 文件夹发给技术人员 |
| 提示端口被占用 | 程序会自动换用 8090 等备用端口，以窗口显示的地址为准 |
| 手机扫码打不开 | 确认同一 Wi-Fi、防火墙已放行（重新运行 `1-启动系统` 并在授权弹窗点「是」）、无设备隔离 |
| 忘记管理员密码 | 运行 `5-重置管理员密码` |
| 测试时大屏更新时快时慢 | 同一个浏览器里开太多页面会占满浏览器对同一网址的连接数（http 下最多 6 条），新版已把每个页面的实时连接减到 1 条、后台页面自动释放；测试时仍建议手机页面用无痕窗口或另一个浏览器打开。现场每部手机、大屏电脑是独立设备，不受影响 |

## 开发者：手动方式

不使用安装包时，也可以按《部署说明》安装 Node.js 22 与 PostgreSQL 16 后执行 `npm ci`、`npm run build`、`npm run db:migrate`、`npm run admin:create`、`npm start`。

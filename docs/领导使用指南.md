# 领导使用指南（手机竞标）

> 可直接转发给参会领导。全程只需「扫一下」，无需下载 App、无需账号密码。

## 会前 / 入场

每位领导会拿到一张本单位专属的 **领导使用卡**：

1. **连 Wi-Fi**（仅局域网版，卡上有此步时）：用手机**自带相机**扫卡上第一个二维码，点「加入网络」。已经连上会场 Wi-Fi 可跳过。
2. **进入竞标页**：用手机**自带「相机」**对准卡上的大二维码，点屏幕上弹出的链接，自动进入本单位页面（显示单位名称和组别）。
   - 用相机打开的是手机自带浏览器（Safari / Chrome 等），不经过微信，不会出现微信的拦截或「非微信官方网页」提示。
   - 少数安卓手机的相机不识别二维码：可用微信「扫一扫」，如提示「非微信官方网页」点「继续访问」。
3. 以后再次打开：**用同样的方式**再扫一次卡上的二维码即可回到页面。

> **同一时间只有一部手机在线。** 需要换手机（或换浏览器）时，直接用新手机扫同一张卡即可，旧手机会自动显示「已下线」，不需要找工作人员重新发码。请勿转发二维码。

## 现场操作

| 时机 | 操作 |
| --- | --- |
| 拿到卡后（会前即可） | 页面出现「确认认领基础底标」，核对金额后点「确认认领」；理财、基金各认领一次（页面顶部可切换） |
| 主持人宣布轮到本组 | 页面按钮变为可点，选择追加幅度（−/＋ 微调或点 +1/+5/+10，整数个百分点） |
| 追加 | 页面实时显示「追加后 ××%、目标 ××万元」；点「确认追加 +N 个百分点」→ 弹窗核对「原增幅 → 新增幅」和竞标目标金额 → 点「确认提交」 |
| 完成 | 看到绿色的「追加成功 · 服务器已确认」和回执号，大屏同步更新 |

- 增幅**只增不减**，确认后不能自行下调；每次追加为 1 个百分点的整数倍（至少 +1），组内自由加码。
- **点错了、加多了**：请立即举手告知工作人员，经现场确认后由工作人员更正（不会低于首轮增幅）。
- 按钮灰色时，下方会写明原因：等待首轮发布、尚未轮到本组、竞标已暂停、本组已结束等，请等待主持人安排。
- 若显示「结果待核验」：是网络波动，系统会自动核对，**不要重复点击**；仍有疑问请举手。
- 若显示「当前增幅已更新，请重新确认」：说明本单位已有一笔追加先成功了，看清最新增幅后再决定。

## 常见情况

| 现象 | 处理 |
| --- | --- |
| 扫码后打不开页面 | 局域网版：确认手机已连会场 Wi-Fi（不要用 4G/5G 流量）；互联网版：用手机流量或任意网络均可，检查信号 |
| 提示「本机未登录或已下线」 | 本单位已在另一部手机登录，或工作人员让本机下线了。要在这部手机继续，再扫一次卡上的二维码即可，已提交的数据不受影响 |
| 提示「二维码已失效」 | 工作人员已作废或重发了二维码，请找工作人员出示新的二维码 |

# 金山文档接入说明

领导用**微信打开金山文档**，在本单位的工作表里填写；工作人员看到表格有人填写后，在会场电脑上的竞标程序（Windows 一键包）点一下「**读取金山表格**」，程序读取一次并按与手机网页**完全相同的规则**处理，大屏同步更新，处理结果写回表格。

不需要租服务器、买域名、备案，也不需要领导连会场 Wi-Fi。

```
领导微信 ──> 金山文档：本单位文件（只读信息区 + 填写「加到多少」「确认」）
                  ▲ 写回处理结果                │ 工作人员点「读取金山表格」时读取
                  │                              ▼
          竞标总控文件（同步脚本，只有工作人员能打开）◀── AirScript 脚本令牌
                                                 ▲
          会场电脑：竞标程序（规则判断 → 数据库 → 大屏 / 管理端 / 导出）
```

**两种方式（管理端「金山文档」页上选择）：**

| | 每家单位一个文件（推荐） | 一个文件 16 张工作表 |
| --- | --- | --- |
| 各单位能否看到别家 | **看不到**：每个文件只分享给本单位领导 | **看得到**：同一文件里的工作表对所有协作者可见（区域权限只能限制编辑，不能限制查看） |
| 准备工作 | 导入 17 个文件（1 个总控 + 16 个单位），复制 16 个文件链接 | 导入 1 个文件 |
| 同步脚本放在 | 总控文件（不分享给领导） | 这个文件 |

正式活动请用「每家单位一个文件」：领导在填写时（尚未确认的数字）、首轮发布前的底标等，都不会被其他单位看到。

> **当前状态**：程序端已完成，并已用「模拟金山文档」完整测试（模拟器运行的就是同一份 AirScript 脚本）。
> 在真实金山文档上还需要做一次实测，见第七节清单。脚本接口按金山文档官方「AirScript 脚本令牌」文档实现；
> 本开发环境无法访问 kdocs.cn，未能在真实表格上运行。

## 一、先用模拟金山文档演练（不需要金山账号）

1. 启动系统，管理端新建演示活动（或正式活动并导入首轮数据）。
2. 打开活动 →「金山文档」，选好方式（默认「每家单位一个文件」）→「使用模拟金山文档」。系统会建好模拟文件并写入版式。
3. 点「一键连接」。之后每次在模拟表格里填写后，到管理端点「读取金山表格」（「现场控制」页面顶部也有）。
4. 在「演练与重新测试」中点单位名称（如「浦东」），打开该单位的模拟文件。这个页面模拟金山文档，黄色格子可填，其余只读；浦东的文件里只有浦东一张表。
   - 手机与电脑连同一 Wi-Fi 时，把地址里的 `localhost` 换成电脑的局域网 IP，就能用手机打开。
5. 按正常流程演练：「首轮数据」发布 →「现场控制」开放第一组 → 在模拟表格里确认底标、填写「加到」→ 看大屏。

模拟表格只存在内存中，程序重启后需要重新点「使用模拟金山文档」。

## 二、表格版式（每家单位一张工作表，表名 = 单位名称；两种方式版式相同）

| 位置 | 内容 | 谁填 |
| --- | --- | --- |
| A1 | 标题 | 程序 |
| B2:B10 | 单位、组别、当前专场、状态、底标、首轮增幅、**当前生效增幅**、当前目标、**下一步可选「加到」** | 程序 |
| E2 | 最近同步时间 | 程序 |
| **B11** | 认领底标：选「确认」 | **领导** |
| C11 | 认领结果 | 程序 |
| 第 12 行 | 表头：序号、加到（%）、确认、处理结果、处理时间 | — |
| **第 13 行起 B 列** | 加到多少（如 35） | **领导** |
| **第 13 行起 C 列** | 选「确认」 | **领导** |
| 第 13 行起 D、E 列 | 处理结果、处理时间 | 程序 |

工作表名称必须与单位名称完全一致：浦东、闵行、宝山、嘉定、奉贤、松江、黄浦、虹口、静安、普陀、长宁、徐汇、杨浦、青浦、金山、崇明。可以多一张「使用说明」表，程序不读它。

## 三、接入真实金山文档（工作人员，约 30–40 分钟，只需做一次）

以「每家单位一个文件」为例；「一个文件 16 张工作表」的差别见本节末尾。

1. **下载模板**：管理端「金山文档」→ 选「每家单位一个文件」→ 展开「第一次使用」→ 下载「模板压缩包」并解压，得到 17 个文件：`00-竞标总控（只给工作人员）.xlsx` 和 `01-浦东.xlsx` … `16-崇明.xlsx`。
2. **导入金山文档**：在金山文档网页版（电脑浏览器）用单位账号登录，新建 → 导入本地文件，把 17 个文件一起上传，建议放在同一个文件夹。不要改文件里的工作表名称。
3. **粘贴脚本（只在总控文件里）**：打开「竞标总控」→ **AirScript 脚本编辑器**（菜单一般在「效率」→「高级开发」，名称以金山文档当前界面为准）→ 新建**共享脚本**，删除默认内容，粘贴管理端下载的「同步脚本」**全文**，保存。不要修改脚本。
4. **添加云文档服务**：在脚本编辑器的「服务」中添加「**云文档**」（脚本需要用它打开 16 个单位文件；名称以当前界面为准）。
5. **脚本令牌**：在脚本编辑器中点「脚本令牌」，生成并复制令牌。令牌相当于运行该脚本的钥匙，请妥善保存。
6. **webhook 链接**：在脚本列表中该脚本的「…」菜单里点「复制 webhook 链接」。链接形如 `https://www.kdocs.cn/api/v3/ide/file/…/script/…/sync_task`。
7. **16 个单位文件链接**：逐个打开单位文件 → 分享 → 复制链接，整理成每行「单位名称 链接」，例如：

   ```
   浦东 https://www.kdocs.cn/l/xxxxxxxx
   闵行 https://www.kdocs.cn/l/xxxxxxxx
   ```

   顺序不限；直接粘贴金山分享时自带的文字也可以，只要每行有单位名称和链接。页面会实时显示「已识别 n / 16 家」。
8. **一键连接**：把 webhook 链接、脚本令牌、16 家文件链接粘贴到管理端，点「**一键连接**」。程序依次完成并逐项显示结果：
   - ✔ 保存链接与令牌
   - ✔ 测试连接（16 家单位文件都能打开）
   - ✔ 写入表格版式（标题、标签、表头、序号）
   - ✔ 启用读取（默认手动读取；不想马上启用，取消勾选「连接后立即启用读取」）

   哪一步显示 ✘，后面会写明原因（例如「浦东：无法打开文件」），对照第八节处理。
9. **分享**：每个单位文件**只分享给对应单位的领导**，权限「可编辑」；「竞标总控」不分享。建议再给单位文件设置区域权限：领导只能编辑 **B11** 和报价区的 **B、C 两列**（B13:C52），其余只读。
10. 首次启用时，表格里已经填写的报价行会标记为「开始同步前已填写」，不参与竞标。
11. 用 2 部手机（iPhone、安卓各一）在微信里打开各自单位的文件，按第四节完整走一遍。

**一个文件 16 张工作表**：第 1 步下载「填报表模板」（一个文件），第 3 步把脚本粘贴在这个文件里，不需要第 4、7 步；第 9 步把这个文件分享给 16 位领导，并为每张工作表设置区域权限（只限制编辑，彼此仍可看到）。

## 四、领导怎么填（可转发给领导）

1. 在微信中打开工作人员分享的金山文档（本单位的文件；如果是一个文件 16 张表，切换到**本单位**的工作表）。
2. 专场开始后，B11 旁边会提示「请在 B11 选择『确认』」。在 B11 选「确认」，C11 显示「已确认」即可。
3. 轮到本组时，在第 13 行起的空行里：**B 列填「加到多少」**（例如 35），**C 列选「确认」**。
4. 工作人员读取后（一般几秒到十几秒），第 8 行「当前生效增幅」更新，D 列显示「✔ 已生效」。若显示「✘ 未生效」，后面会写明原因。D 列还是空的，说明还没被读取，请稍候，不要重复填写。
5. 再次加码请填**下一行**。每行只处理一次，处理过的行再改无效；增幅只增不减，填低了不会生效。
6. 第 10 行「下一步可选」列出现在可以填的数值。

手机屏幕较窄时，D 列「处理结果」可能需要左右滑动才能看到；以第 8 行「当前生效增幅」为准即可。

## 五、规则说明（与手机网页一致）

- **填的是「加到多少」，不是「加多少」**：网络卡顿时重复提交同一个数，只记一次；填低了不生效，不会调减。
- **每行只处理一次**：以本机程序读到该行（B 列有值且 C 列为「确认」）的时间为准。处理后再修改该行，D 列会提示「修改无效，请在下一行填写」。
- **认领底标**：每个专场（理财、基金）首轮发布后，程序先清空 B11 并提示确认，读到之后的「确认」才算认领。上一专场的「确认」不会自动用到下一专场。
- **手动读取（默认）**：程序不会定时自动读取金山表格，避免频繁调用金山文档（金山官方未公布脚本令牌的每日调用上限）。现场安排一位工作人员盯着金山表格：看到有人填写，就在「现场控制」页面顶部点「**读取金山表格**」。每点一次只调用一次，按钮旁显示本次结果，例如「新生效 2 条（浦东、闵行）」。
- 以下操作会附带读取一次（每次一次调用）：发布首轮、开始、开放/结束本组、暂停、恢复、锁定之后，把最新状态写到领导表格；结束本组、暂停、锁定之前，先把最后的填写读进来。一场活动大约多出十几次调用。
- 如果确实需要自动读取，可在「高级设置」勾选「自动定时读取」（不推荐）：有组竞标时按同步间隔，等待、组间、暂停时每 10 秒，首轮未发布时每 30 秒，全部锁定后停止。
- **结束本组、暂停、锁定前**，管理端会先自动读一次表格，把最后几秒的填写读进来。如果当时读取失败，操作照常执行，但会提示「最后几秒的填写可能未读入，请核对表格」。
- **底标、首轮、档位、组别、并列、标王**等判断全部由程序完成，与手机网页、管理员代录是同一套逻辑。台账导出中来源标注为「领导提交（金山文档）」。
- 手机网页扫码和金山文档可以同时使用，互不影响；工作人员「代录」「代记」也照常可用。

## 六、现场注意

- **会场电脑必须能上互联网**（访问 kdocs.cn）；大屏、管理端仍在这台电脑或会场局域网内使用。
- **安排一位工作人员盯表**：在电脑上打开金山文档（每家一个文件时，可打开存放 16 个文件的文件夹看「最近更新」，或把 16 个文件分别开在浏览器标签页里），看到有人填写就点「读取金山表格」。也可以由领导在现场口头示意「已提交」后再点。
- 「金山文档」页显示读取状态：最近一次读取的结果、调用次数、失败原因、缺少的工作表、最近处理的填写。
- **金山文档不可用或会场断网时**：暂停竞标，工作人员看着表格（或电话确认），用「现场控制」中的「代录」录入，恢复后继续点读取即可。
- 程序重启后不会自动读取，点一次「读取金山表格」即可继续。未认领底标的单位，B11 会被重新清空并提示确认一次。

## 七、真实金山文档实测清单（正式使用前完成）

| # | 检查项 | 怎么做 | 通过标准 |
| --- | --- | --- | --- |
| 1 | 脚本能运行、能返回结果、能打开单位文件 | 「一键连接」 | 「测试连接」一项显示「16 家单位文件都能打开」 |
| 2 | 能写回 | 「初始化表格版式」 | 各表出现标题、标签、表头、序号 |
| 3 | 读取耗时 | 连续点 20 次「读取金山表格」 | 每次都成功；把「耗时」记入验收记录（每家一个文件时每次要打开 16 个文件，耗时会比一个文件长） |
| 4 | 互相看不到、不能改 | 用 A 单位领导账号尝试打开 B 单位文件、修改本单位信息区 | 打不开别家文件；信息区不能修改 |
| 5 | 微信打开体验 | iPhone、安卓各一台，关闭 Wi-Fi，在微信中打开表格并完整填写 | 能选择「确认」、能填数字；工作人员点读取后结果出现在表格里 |
| 6 | 多人同时填写 | 3 位以上同时在各自工作表填写 | 全部正确处理，无串表 |
| 7 | 令牌有效期 | 隔天再「测试连接」 | 仍然可用（如会过期，会前一天重新生成并填入） |

若第 1 项提示「脚本没有返回结果」，说明当前金山文档版本取返回值的方式与文档不同；若提示「无法打开文件」，先确认第 4 步已添加「云文档」服务、链接是单位文件的分享链接、令牌所有者能打开这些文件。仍不行请把提示原文和脚本编辑器中的运行日志截图发给开发人员。

> 「每家单位一个文件」用到的 `KSDrive.openFile`（脚本打开其他文件）来自 AirScript 的类型定义，尚未在真实金山文档上验证；如果第 1 项始终打不开单位文件，可先改用「一个文件 16 张工作表」，再联系开发人员。

## 八、常见提示

| 提示 | 原因与处理 |
| --- | --- |
| 脚本令牌无效、已过期或无权运行该脚本 | 重新生成令牌，在管理端填入（只填令牌，链接不变） |
| 脚本没有返回结果 / 脚本版本与本程序不匹配 | 从管理端重新下载脚本，在编辑器中**整体替换**后保存 |
| 缺少工作表：×× | 工作表名称与单位名称不一致，或被删除；改名后「初始化表格版式」 |
| ××：无法打开文件 | 每家一个文件时：确认已添加「云文档」服务、该行是单位文件的分享链接（不是 webhook 链接）、令牌所有者能打开该文件 |
| 还缺 n 家单位的文件链接 / 用了同一个文件链接 | 检查 16 家文件链接清单，每行一家，单位名称写全 |
| 脚本版本过旧，不支持「每家单位一个文件」 | 从管理端重新下载同步脚本，在总控文件中整体替换 |
| 调用过于频繁，金山文档暂时限流 | 稍等片刻再点读取；如开启了自动定时读取，请关闭 |
| 无法连接金山文档 | 检查会场电脑的互联网连接 |
| 清空填写区前请先停用读取 | 防止现场误删；演练结束后先「停用读取」再清空 |

## 九、以后的活动、反复演练

- 金山文件、脚本、令牌、16 家文件链接**只需准备一次**。新建活动后进「金山文档」页，点「**沿用这张表格，一键连接**」即可（自动使用上一次的链接和令牌）。
- 同一张表格同一时间只能由一个活动读取：新活动启用时，旧活动对这张表格的读取会自动停用，并在页面上提示。
- **新建一个演示活动**，沿用同一张表格并一键连接。表格里已有的报价行会自动标记为「开始同步前已填写」，不影响新活动。
- 想让表格干净：先「停用读取」，再点「清空表格填写区」（清空 16 张表的 B11 和报价区 B–E 列）。

## 十、安全

- 脚本令牌保存在本机数据库中，页面上只显示末 4 位；数据库备份文件中也包含令牌，请妥善保管备份。
- 令牌泄露时，在脚本编辑器中重新生成，旧令牌即失效。
- 程序只接受 `kdocs.cn` 的脚本链接（以及本机模拟地址），不会向其他网站发送令牌。
- 表格里只有各单位的底标、增幅与金额，没有个人信息；是否允许把这些数据放在金山文档，请与单位信息科技部门确认。

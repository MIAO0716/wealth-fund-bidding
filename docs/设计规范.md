# 现场界面设计规范

目标：用红色营造竞标的竞赛氛围，同时保持克制、有质感，不艳俗、不刺眼。

## 色彩

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| 中国红 | `#C8102E` | 手机端顶部横幅、主按钮「确认追加」、当前增幅数字 |
| 绛红（深） | `#7A0C18` | 大屏背景主色、按钮按下态 |
| 夜绛（最深） | `#3A060C` | 大屏背景暗角、卡片底 |
| 香槟金 | `#E2B85C` | 大屏标题、当前开放组描边、标王候选标签、加码高亮 |
| 浅金 | `#F6E3B4` | 金色文字的弱化态、分隔线 |
| 暖白 | `#FFF8EE` | 大屏正文、手机端背景 |
| 墨灰 | `#2B2326` | 手机端正文 |
| 中性灰 | `#8C7F80` | 次要信息、等待中/已结束组 |

原则：

- 红色只用在「氛围与强调」：大屏背景、标题栏、主按钮、当前增幅。正文、表格线保持中性。
- 大屏以深绛红渐变为底（中央略亮、四角压暗），文字用暖白，重点用香槟金，对比度满足投影可读。
- 错误与告警不用红色（避免与氛围色混淆）：手机端用墨灰文字 + 琥珀色图标 `#B7791F`；大屏断线提示用浅金底深色字横条。
- 不使用大面积闪烁、整屏动画；加码时单位行金色微光高亮约 2 秒。

## 字体与字号

- 字体：系统中文字体栈（PingFang SC / Microsoft YaHei / Noto Sans CJK），数字使用等宽数字 `font-variant-numeric: tabular-nums`。
- 大屏（1920×1080）：当前增幅约 48px，单位名约 28px，组标题约 32px，页头活动名约 40px。
- 手机端：当前增幅为最大视觉重点（约 56px），按钮至少 44px 高，主按钮 56px。

## 组件

- 大屏三列组卡片：当前开放组金色描边 + 顶部金色角标「进行中」；其他组保持数据，标注「等待」或「已结束」，整体降低亮度。
- 标王候选：金色实心徽标；并列领先·待确认：金色描边徽标；组内领先：浅金文字。
- 手机端二次确认弹窗：白底，标题区中国红细条，明确显示「原增幅 → 新增幅」、目标金额与「确认后不可下调」。
- 「演示」标识：所有演示活动页面右上角固定显示灰底白字「演示」角标。

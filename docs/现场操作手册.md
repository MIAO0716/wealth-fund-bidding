# 现场操作手册（工作人员）

适用：理财、基金现场竞标。流程：**会前导入并一起冻结理财、基金首轮 → 认领 → 理财分组加码 → 锁定理财 → 基金分组加码 → 锁定基金 → 导出**。

主持人台词见《主持人讲话稿》，其中【操作】提示与本手册一致。

## 角色分工建议

| 岗位 | 设备 | 职责 |
| --- | --- | --- |
| 主控 | 电脑 1（管理端） | 开组/结束组、暂停、锁定、切换大屏、代录与更正；必要时执行「在线版 → 局域网版」切换 |
| 投屏 | 电脑 2（大屏链接，全屏） | 只负责投屏，不做操作 |
| 联络 | 手机/对讲 | 协助领导扫码、处理断网代录、记录口头确认；保管「备用·局域网」领导卡 |

## 会前（建议提前一天）

1. **登录管理端** `/admin`，新建正式活动。
2. **准备与配置**：只需填写**活动名称**和**活动日期**，点「保存配置」。其他设置收在「其他设置（一般不用改）」里；目标金额按「底标 ×（1 + 增幅）」自动计算，大屏默认展示。
3. **首轮数据**：下载空白模板（Excel 或 CSV）→ 在**同一个文件**里填写理财、基金两个项目共 32 行的底标（万元）与首轮增幅（整数百分点，30% 填 30）→ 上传 → 查看校验结果：
   - 有任何红色错误行，整批不会写入，按提示修改后重新上传；
   - 全部通过后点「整体提交」。
   - 也可在表格中逐家「录入/修改」。
4. **一起冻结首轮**：页面顶部显示「理财：已录入 16/16」「基金：已录入 16/16」后，点「**一起冻结理财、基金首轮**」→「确认冻结」。冻结后底标与首轮增幅不可修改；这是会前准备，**竞标现场不需要再操作「首轮数据」页**。
5. 「准备与配置」页右侧「正式开启前检查」应全部通过。
5. **二维码与大屏**：
   - 先在「准备与配置」填写**会场 Wi-Fi 名称和密码**（选填，填写后使用卡上会印「扫码连 Wi-Fi」二维码）；
   - 「16 家领导使用卡（生成 / 打印）」→ 打印：**每页 A4 一个单位**，上半部分是该单位会前导入的理财、基金基础底标与首轮增幅，下半部分是专属二维码与使用说明（建议在首轮冻结后打印，卡上会标注「已冻结」）；按单位装入信封；
   - **每家单位一个固定二维码，活动期间不变**：随时再点这个按钮（或该单位的「显示二维码」）看到的都是同一个码，可补打印，不会让已发出的卡失效；
   - 同一时间只有一部手机在线：领导换手机时直接用新手机扫同一张卡，旧手机自动下线；
   - 把《领导使用指南》转发给参会领导；
   - 「生成大屏链接」→ 复制到投屏电脑浏览器打开，点「全屏」。
6. 冻结后即可把使用卡发给领导，请领导会前扫码**认领理财、基金底标**（手机上可切换理财/基金分别认领）。
7. **彩排**：建议用「新建演示活动」完整走一遍两项目流程（演示活动所有页面标有「演示」，与正式活动完全隔离）。
8. 如配置了自动备份，确认「导出与备份」页能生成检查点。

## 会议现场

### 1. 领导扫码进入

- 领导用**手机自带相机**扫描本单位二维码（推荐；相机扫不出时用微信「扫一扫」），进入后页面显示单位名称、组别、底标、首轮增幅。再次进入时用同样方式扫码。
- **换手机**：直接用新手机扫同一张卡即可，旧手机自动显示「已下线」。**同一时间只有一部手机在线。**
- 「二维码与大屏」页「在线手机」一栏显示每家是否在线；大屏右上角显示「领导在线 N/16」（锁屏、切后台不超过 1 分钟仍算在线）。
- 需要让某部手机下线（例如手机被别人拿走），点该单位「**强制下线**」；领导再扫原来的码即可重新登录。
- 卡丢了：点该单位「**显示二维码**」，电脑屏幕上会显示同一张卡，**让领导直接扫电脑屏幕**即可。

### 2. 首轮展示与认领底标

- 首轮已在会前冻结，大屏默认显示**理财首轮结果**（含底标与目标金额）。
- 领导手机出现「确认认领基础底标」按钮，请领导确认（可在会前或等待阶段完成）。
- 领导无法操作时，可在「现场控制」榜单中点「**代记**」，弹窗确认即可。

### 3. 分组现场加码

- 「现场控制」→ 理财 →「开始竞标」，大屏自动切到实时榜。
- 「现场控制」右上角显示**网络延迟**（管理电脑到服务器的往返时间，每 5 秒测一次）：绿色 <200 ms 良好，黄色较慢，红色很慢或「无法连接服务器」时先检查管理电脑网络（可开手机热点）。
- 「开放本组」：第一组 → 结束本组 → 第二组 → 结束本组 → 第三组 → 结束本组。
- 同一时间只能开放一个组；未轮到的组手机端显示「尚未轮到本组」。
- 领导操作：用 −/＋ 或 +1/+5/+10 选好追加幅度 → 「确认追加 +N 个百分点」→ 核对「原增幅 → 新增幅、目标金额、确认后不可下调」→ 确认提交 → 看到「追加成功 · 服务器已确认」和回执号才算成功。
- 大屏：**只显示正在竞标的这一组**（顶部有三组进度条），每家显示首轮增幅、当前增幅和按增幅实时计算的**竞标目标金额**；标王候选（≥30% 且唯一第一）/ 并列领先·待确认 / 暂无达到 30% 的标王候选；底部滚动本组最近加码。
- 「结束本组」后，大屏**停留在本组最终结果**（「本组竞标结束 · 最终结果」），等下一组「开放本组」时再平滑切换到下一组。
- **领导误操作（加多了）**：在「现场控制」榜单该单位点「代录」→「**下调更正（误操作）**」→ 填正确的增幅 → 确认。锁定前随时可用（本组结束后、暂停时也可以），不能低于首轮增幅；大屏和领导手机立即更新，流水中标注「工作人员更正」。
- 临时暂停：「暂停」→ 所有提交被拒绝，手机显示「竞标已暂停，请等待工作人员」→「恢复」。

### 4. 锁定理财

- 结束第三组后系统自动暂停。
- 与现场核对三组结果 →「锁定项目…」→ 查看并列提示 → 勾选核对 → 确认锁定。**锁定不可退回。**
- **正常锁定要求三组都已结束。** 确需提前收场（如时间不足），锁定窗口会列出未结束的分组，须单独勾选「确认提前收场」，记入审计。
- 使用金山文档时：结束本组、锁定前会自动读取一次表格；有单位没读到会被拦截，核对这些单位的最后报价后弹窗确认即可继续。
- 若某组**并列第一**：系统只提示「并列第一·授旗规则待确认」，不会自动认定唯一标王。如组织者决定组织追加，可在锁定前「重新开放」该组（弹窗确认，原增幅不会下调）。
- 管理端所有操作都**不需要填写原因**，只需在弹窗中确认；操作人和时间自动记入审计。
- 「大屏展示」→「最终结果」可展示锁定结果：每家显示首轮、加码（+N 个百分点）、最终增幅和竞标目标（万元，取整）。每个项目下方显示**全市合计**：基础底标合计 → 最终竞标目标合计（亿元，保留 2 位小数）和全市增幅。

### 5. 基金

- 理财锁定后，领导手机**自动切到基金专场**（基金首轮已在会前冻结），未认领的领导认领基金底标。
- 「现场控制」选「基金」，「大屏展示」点「首轮结果」展示基金首轮；然后按理财同样流程开放各组、锁定。

### 大屏声音

- 「现场控制」→「大屏展示」里有「**大屏声音：开 / 关**」（默认开），可点「试听加码音」「试听标王音效」在管理电脑上试听。
- 普通加码响一声「叮」；**出现新的标王候选**（增幅 ≥30% 且组内唯一第一）时播放一段上扬的标王音效，大屏中央同时弹出「新标王候选：××」。
- 投屏电脑打开大屏后**点一下页面**（例如点「全屏」），浏览器才允许播放声音；未点击时大屏右上角会提示「点击任意处开启声音」。

### 6. 导出

- 「导出与备份」→「导出 Excel（四个工作表）」：首轮结果、最终竞标台账、加码流水、确认与控制记录。
- 两项目都锁定后导出的为**最终公示台账**；未锁定时文件会标注「过程数据」。
- 打印最终竞标台账用于签字备案（手机上的「确认认领」仅用于现场留痕）。
- **删除活动**：管理端首页活动列表点「删除」→ 勾选确认 →「确认删除」，该活动的全部数据（首轮、流水、结果、二维码、操作记录等）一并删除，不可恢复。竞标进行中的活动不能删除；正式活动请先导出台账。配置了备份目录时，删除前会自动生成一份检查点备份。

## 异常处理

| 情况 | 处理 |
| --- | --- |
| 手机显示「结果待核验」 | 网络超时，系统自动核验同一请求；不要让领导重复点击。核验结果为成功即以回执为准；显示「服务器未收到」时点「用同一请求重试」 |
| 手机显示「当前增幅已更新，请重新确认」 | 同单位另一部手机或代录已先提交，请领导看清最新增幅后重新确认 |
| 领导手机断网 | 手机端停止提交，不会离线排队。联络员记录领导口头确认的目标增幅，网络恢复或在管理端「代录」：按真实差额代录一笔（如差 23 个百分点就录 +23），不虚构时间 |
| 领导点错、加多了 | 现场与领导确认正确增幅后，「代录」→「下调更正（误操作）」改回；不能低于首轮 |
| 领导要换手机 | 用新手机扫同一张卡，旧手机自动下线；二维码不变 |
| 大屏没有声音 | 「现场控制」→「大屏展示」确认「大屏声音：开」；在投屏电脑的大屏页面点一下（如「全屏」），浏览器才允许出声；可点「试听」检查 |
| 大屏显示「连接中断，数据可能延迟」 | 大屏保留最后一次已确认数据；检查投屏电脑网络。SSE 不可用时自动降级为每 2 秒刷新 |
| 后端不可用 | 暂停现场流程，大屏只显示最后快照；不要在电脑本地自行改数。恢复见《部署说明》 |
| 冻结后发现底标/首轮错误 | 系统不允许修改已冻结数据。暂停 → 导出记录 → 经组织者确认后「新建正式活动」并关联原活动 → 重新导入、冻结。原活动保留 |
| 增幅很大时手机要求再次确认 | 达到配置的阈值（默认 100%）时需勾选确认，这不是上限 |

## 在线版为主、局域网版备用（切换步骤）

正式活动用**在线版**（云服务器，领导用手机流量扫码）；会场一台 Windows 电脑装好**局域网版**作为备用。两套系统数据互不相通，**同一时间只能以一套为准**。

### 会前准备（两套都要做）

| | 在线版（正式） | 局域网版（备用） |
| --- | --- | --- |
| 地址 | `http://云服务器地址/admin`（有域名后为 `https://域名/admin`） | 会场电脑上运行「1-启动系统」，`http://localhost:8080/admin` |
| 活动 | 新建**正式活动** | 同样新建**正式活动**，名称后加「（备用）」 |
| 配置 | 填写活动配置；**Wi-Fi 两项留空** | 配置与在线版**完全一致**（快捷档位、阈值等）；**填写会场 Wi-Fi 名称和密码** |
| 首轮数据 | 上传首轮 Excel，校验通过后提交，一起冻结 | 上传**同一个** Excel，校验通过后提交，一起冻结 |
| 领导卡 | 打印一套，**会前发给领导** | 也打印一套（二维码默认 30 天有效），装入信封标注「**备用·局域网**」，由联络员保管，**不发** |
| 大屏链接 | 生成，投屏电脑打开 | 也生成一个，保存在投屏电脑的浏览器书签里备用 |
| 测试 | 关掉手机 Wi-Fi，用流量扫一张演示卡走一遍 | 手机连会场 Wi-Fi，扫一张演示卡走一遍 |

- 会前把在线版、局域网版的管理员密码分别写给主控和联络两人。
- 会场至少准备一部能开热点的手机，给管理电脑和投屏电脑应急用。

### 先判断：要不要切换

**以下情况不切换**，按括号处理即可：

- 只是管理电脑或投屏电脑上不了网（给这两台电脑开手机热点）；
- 个别领导打不开页面（换另一种方式扫码、用另一部手机扫同一张卡，或在「现场控制」**代录**；如已准备金山文档，也可让该领导在金山表格中填写）；
- 手机显示「结果待核验」（等系统自动核验，不要重复提交）。

**同时满足以下两条才切换**：

1. **3 家以上**单位用手机流量都打不开在线版，并且工作人员用自己的手机流量打开 `在线版地址/admin` 也打不开；
2. 持续 **3 分钟以上**没有恢复。

切换由主控提出、现场负责人同意后执行。

### 切换步骤（约 10–15 分钟）

**第 1 步：暂停并宣布**
- 在线版还能打开：在「现场控制」点「**暂停**」。
- 主持人宣布：「系统切换，暂停竞标几分钟，请各位稍候。」

**第 2 步：记下当前结果（两人一起核对）**
- 在线版还能打开：「导出与备份」→ 导出 Excel；或对「现场控制」榜单截图。
- 在线版打不开：用**大屏最后的画面**（大屏会保留最后一次已确认的数据）拍照，并让各单位领导出示手机上最后一张「追加成功」回执。
- 逐家记下：**当前增幅、是否已确认底标**，以及哪些组已结束、当前进行到第几组。

**第 3 步：在局域网版补录**
1. 确认「首轮数据」已一起冻结（会前应已完成）。
2. 「现场控制」→「开始竞标」，开放**第一组**。
3. 对已确认底标的单位，点「**代记**」并确认。
4. 对增幅已高于首轮的单位，点「**代录**」补到记下的当前增幅。差额一笔录完，例如首轮 30%、当前 53%，就录 +23。补录依据（××:×× 截图/大屏照片）由联络员另行记录。
5. 第一组补完后点「结束本组」，再开放下一组，按同样方法补录。一直补到故障时正在进行的那一组，**补完后让这一组保持开放**，然后点「暂停」。
6. **两人逐家核对**局域网版榜单与第 2 步的记录，完全一致后再继续。

> **如果理财已经锁定、在基金阶段出的故障**：先按理财的最终结果在局域网版补录理财（三组都补完并结束），正常锁定理财；再按上面的方法补录基金。

**第 4 步：换大屏**
投屏电脑打开局域网版大屏链接（书签里），点「全屏」。

**第 5 步：领导重新扫码**
- 联络员把「备用·局域网」卡发给各单位领导。
- 领导先用相机扫卡上第一个二维码**连会场 Wi-Fi**，再用相机扫第二个二维码进入。
- 告诉领导：**原来的卡停用，之后只用这张备用卡**。

**第 6 步：恢复竞标**
在局域网版「现场控制」点「恢复」，主持人宣布继续。

### 切换之后

- 本场活动**以局域网版为准**：锁定、导出台账、签字备案都在局域网版完成。
- 在线版恢复后**不要再在上面操作**，它的数据保留作为切换前的记录。
- 会后在活动记录中写明：切换时间、原因、补录依据（截图/照片），与两套系统导出的台账一起归档。
- 如使用了金山文档：切换后先不用金山通道，金山表格仍连着在线版。

## 注意事项

- 正式活动不提供一键清空；演示重置只能新建演示活动。
- 二维码、大屏链接不要投屏或外传；领导会话与二维码可随时在管理端撤销。
- 所有操作（发布、开闭组、暂停、锁定、代记、代录、导出）都记录在「监控与审计」。
